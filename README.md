# Nexus Admin Dashboard

The Nexus Admin Dashboard is a web-based administrative platform designed to manage and monitor the Nexus mobile application. The Nexus platform aims to raise awareness of the United Nations Sustainable Development Goals (SDGs) by providing educational content and tracking user engagement.

This dashboard enables administrators to monitor users, analyze engagement metrics, review feedback, and maintain platform operations efficiently.

## Features

- User monitoring and analytics
- Active and engaged user tracking
- Feedback monitoring
- Dashboard analytics and summary metrics
- Secure Firebase integration
- Responsive and modern user interface

## Technologies Used

- Next.js
- React.js
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- JavaScript (ES6+)
